# Architecture Decisions

Record a decision here only when it has durable consequences across tools or future changes.

Use the filename format `NNNN-short-title.md`.
Keep the directory named `docs/adr/`: the agent skills that read decisions before working in an area look there by path, and a renamed directory makes those decisions invisible to them.

Each decision record must state the context, the decision, alternatives considered, and consequences.
